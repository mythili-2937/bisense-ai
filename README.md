# BISense AI

## AI-Powered Standards Intelligence for Procurement

BISense AI is a prototype AI-powered recommendation system designed to analyze procurement requirements and tender documents and identify potentially relevant Indian Standards.

## Features

- AI-based procurement requirement analysis
- Semantic standards recommendation
- Tender PDF analysis
- Allied standards discovery
- Compliance summary
- Multilingual support
- Downloadable PDF reports
- Standards explorer

## How It Works

Procurement Requirement / Tender PDF  
→ AI Requirement Understanding  
→ Semantic Search  
→ Standards Recommendation  
→ Allied Standards Discovery  
→ Compliance Summary  
→ Explainable Recommendation Report

## Technology Stack

- Python
- Streamlit
- Gemini
- Sentence Transformers
- FAISS
- PyMuPDF
- ReportLab

## Prototype Notice

This project is a prototype developed for hackathon demonstration purposes.

Recommendations generated by BISense AI must be verified against authoritative BIS sources before being used for actual procurement or compliance decisions.
